被动语态基本语法：
---------------------
be动词 + 过去分词
    |                 |
 时态           被动
---------------------

现在式被动语态：beV + p.p.

过去式被动语态：was/were + p.p.

现在进行时被动语态：
    am/are/is + Ving
+                       beV	 + p.p.
= am/are/is +  being + p.p.

过去进行时被动语态：
    was/were + Ving
+                       beV	 + p.p.
= was/were +  being + p.p.

未来式的被动语态：
(助动词will + 原型动词VR，助动词后需跟原型动词，其它助动词:can、must、should...等的被动语态形成语法，和未来式一样。)
   will + VR            
+           beV + p.p.
= will + be   + p.p.

   am/are/is going to  + VR
+                                      beV + p.p.
= am/are/is going to +  be + p.p.

现在完成式的被动语态：
   have/has +  p.p.
+                     beV   + p.p.
= have/has + been + p.p.
